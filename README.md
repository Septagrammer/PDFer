# PDFer

Android-приложение для чтения PDF, в том числе сканов. Оно распознаёт текст
локально через Tesseract, пытается сохранить порядок колонок и показывает
переформатированный текст с картинками, поиском и настройками чтения.

## Возможности

- Открытие PDF из системного picker или через «Открыть с помощью».
- Локальный OCR для английского, русского, украинского и чешского языков.
- Поиск по документу, сохранение последней страницы и просмотр оригинала.
- Светлая, сепия и тёмная темы, размер и интервалы текста, serif-шрифт.
- Режим Fast встроен в приложение. Режим Best скачивает модели по запросу.

## Данные

Импортированный PDF хранится только в private storage приложения. Библиотека
фиксируется атомарно до того, как документ появится в интерфейсе; повторный
импорт тех же байтов не создаёт дубликат. OCR-кэш можно безопасно удалить
вместе с документом. Удаление требует подтверждения.

## Сборка и тесты

Нужны Android SDK и JDK 21:

```sh
export JAVA_HOME=/Library/Java/JavaVirtualMachines/temurin-21.jdk/Contents/Home
./gradlew :app:assembleDebug
./gradlew :app:testDebugUnitTest
```

Для instrumented tests нужен запущенный emulator или Android device:

```sh
./gradlew :app:connectedDebugAndroidTest
```

Проверено 2026-11-10: debug APK и APK instrumented tests собираются, 51 JVM-тест
проходит. Проверки интерфейса и instrumented tests на устройстве пока не выполнены.

## Ограничения

Распознавание и порядок текста на плохих много-колоночных сканах зависят от
качества исходника. Best требует интернет для первичного скачивания моделей;
при неудаче приложение продолжает работать с Fast.
